## Exercice 1 — La navigation

### Objectif
Créer une **navigation dans la page `index`** permettant d’accéder à chaque exercice du projet.

### Contexte
Les différentes pages d’exercices se trouvent dans l’arborescence suivante :

src/
└── pages/
    └── positions/
    └── grilles/
selecteur
textes
fond_bordure
couleurs
boites
unites
flexbox

### Consignes

1. Dans la page **`index`**, créez une **barre de navigation horizontale**.
2. Cette navigation doit contenir **un lien pour chaque exercice**.
3. Chaque lien doit **rediriger vers la page correspondante** située dans le dossier `pages`.
4. Le **nom de chaque lien** doit correspondre **au numéro de l’exercice**.

### Exemple attendu

Exercice 2 = Sélecteurs
Exercice 3 = textes
Exercice 4 = fond_bordure
Exercice 5 = couleurs
Exercice 6 = boites
Exercice 7 = unites
Exercice 8 = flexbox
Exercice 9 = positions
Exercice 10 = grilles
Exercice 11 = 


Chaque lien doit permettre d'accéder à la page correspondante dans le dossier `pages`.

### Critères de réussite

- La navigation est visible dans la page `index`.
- Chaque lien fonctionne correctement.
- Les liens respectent la **numérotation des exercices**.
- Le code est **propre et bien structuré**.
